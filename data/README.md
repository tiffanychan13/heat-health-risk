# Data

Data files are not committed. Download them into the folders below.

| Folder | Contents | Source |
|---|---|---|
| `raw/` | CDC Heat & Health Tracker county-level ED-visit series; NWS forecast archive | CDC, NWS |
| `external/` | CDC/ATSDR Social Vulnerability Index; cooling-center locations | CDC/ATSDR, city open-data portals |
| `processed/` | Cleaned, merged, model-ready tables produced by `src/heatrisk` | generated |

Record the download date and URL for each file in `docs/data_log.md` so results are reproducible.
