# Data

Data files are not committed. Download them into the folders below.

| Folder | Contents | Source |
|---|---|---|
| `raw/` | Daily citywide heat-related ED visits; NWS MOS forecasts and heat advisories; NOAA daily observations; NYS heat-stress hospitalizations | NYC EH Data Portal, Iowa Environmental Mesonet, NOAA NCEI, NYS DOH |
| `external/` | NYC Heat Vulnerability Index; Cool It! NYC cooling sites | NYC Open Data |
| `processed/` | Cleaned, merged city-day table and neighborhood table produced by `src/heatrisk` | generated |

Record the download date and URL for each file in `docs/data_log.md` so results are reproducible.
